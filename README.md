# LOL 国服战绩查询

输入玩家 ID 查询《英雄联盟》国服战绩的桌面工具。通过本机已登录客户端取得授权，
优先从腾讯 SGP 战绩服务读取完整历史，LCU 用于连接检测、身份和本地资源。
战绩查询请求直接发送腾讯服务器，不向第三方上传账号凭据或战绩。
静态资料优先读取客户端；必要时联网获取腾讯 CDN / CommunityDragon 的公开资源。

## 界面

全界面采用统一赛博朋克主题：青蓝 / 紫色灯效、左侧功能导航、查询控制区、
胜败战绩卡片、海克斯统计表、双方对局面板和独立开局提醒。
保留「乐✌认证」应用图标；详情窗口可按 Esc 关闭，支持键盘焦点与减少动画设置。

## 使用方法

1. 双击 `LOL战绩查询.exe`（无需安装，免费分享）。
2. 通过 WeGame 登录《英雄联盟》客户端，进入大厅（工具会自动检测并连接）。
   只打开 WeGame 不够；无需进入对局，英雄联盟客户端可以放在后台。
3. 在工具顶部输入玩家 ID，点「查询」：
   - 需输入完整 `名字#Tag`（如 `峡谷之巅#5177`）；Tag 可在对方生涯页查看；
   -      「最多战绩」可选 20 / 50 / 100 / 200 / 300 / 500 场，默认 20 场，查询后自动加载至所选上限；
     加载中显示转圈 + 进度条（已取得 N / 上限 场）并可随时停止，列表按批增量出现而不是最后一次性刷出；
     调大数量会继续补齐，调小数量立即收起较早记录；
     分页按每批 3 页并发拉取（接口单次上限 20 场/页），500 场由 25 次串行往返降到 9 批，比逐页串行快约 2~3 倍；
     先取最近 N 场再按类型和日期筛选，汇总、个人海克斯分析及 CSV 使用相同范围；
     若历史不足，显示实际可获取的全部场次（例如选 500 场、只有 83 场就显示 83 场）；
     分页失败或重复不会被当作历史已取完，会提示错误并允许重试；
   - 「对局类型」可选择海克斯大乱斗（含匹配 2400、自定义 3270）、极地大乱斗、排位、匹配等；
   - 可按开始日期和结束日期筛选，日期采用本机时区，包含结束日期当天；
   - 列表显示每场对局日期和时间，以及海克斯中文名称、图标和稀有度；
   - 点击任意一场可查看两队 10 人详情，每位玩家的海克斯完整列在其数据下方；
   - 每位玩家名字旁有「复制 ID」，优先复制完整 `名字#Tag`；若接口没给 Tag，提示只能复制名称；
   - 显示「好友 / 非好友 / 本人 / 好友状态未知」，始终相对于本机当前登录账号，无法查看别人的好友关系；
   - 统计和「导出 CSV」均使用当前筛选结果，CSV 包含对局时间和海克斯名称。

## 海克斯分析

- **个人战绩分析**：按当前类型、日期和英雄筛选，统计选择海克斯后的胜率、胜场、场次及英雄搭配表现。
  只计海克斯大乱斗，排除重开；同场同海克斯只计一次。缺少强化记录的对局不会算作「未选择」。
  选取/未选取各至少 10 场才比较表现，胜率相差至少 5 个百分点标记偏高或偏低，其余标记接近；
  英雄搭配只与同一英雄未选取该海克斯的记录比较。样本不足仍显示真实胜率和场次。
  这是个人战绩相关性，不是全服强度、因果收益或对英雄机制的适配判定。
- **公开强度 / 英雄适配**：只需联网，不必启动 WeGame 或游戏客户端。
  选择全部英雄查看公开海克斯胜率与 T1–T5 梯队，选择具体英雄查看搭配胜率、梯队和样本数。
  来源为 [ARAMGG 公开海克斯榜](https://aramgg.com/en/augments) 及其公开英雄详情数据。
  来源的总体榜声明使用腾讯国服资料；英雄详情的胜率来自 ARAMGG 客户端上传样本（区域按源数据标记），
  不应视为官方全服胜率。T1 最高，梯队沿用来源，不等同于白银/黄金/棱彩稀有度。
- 公开参考标注来源、来源版本、日期、获取时间及可用样本数；没有提供的数据标为未知，不写成 0%。
  不同页面可能使用不同版本编号格式（如 `26.17` / `16.17`），保留来源原值。
  公开参考不随个人日期筛选；缓存 6 小时，可手动刷新，联网失败时明确标注旧缓存。
  缓存存放于 `%LOCALAPPDATA%\LOL战绩查询\references`，不会向公开服务上传玩家或对局数据。

## 娱乐评分与好友标记

- **伤害评价**：后台读取完整十人详情，显示对英雄伤害的全场排名、全场最高及并列最高。
  对当前类型/日期筛选下最近 20 场非重开对局，计算「伤害最高场次 / 已核验适用场次」，
  占比达到 30%（含 30%）显示达标。并列最高计入，十人全为零不计最高。
  缺少十人数据或身份无法确认时显示统计未完成，可重试；竞技场等非十人模式不参与。
  更早对局可点开详情核验；伤害评价与原娱乐评分分别显示。

- 战绩列表、十人详情显示单局评分；玩家信息栏显示当前筛选下的平均分，排除重开及资料不足的对局。
  列表可按评分降序，详情可在各队内按评分降序，CSV 也包含分数和等级。
- 总分 100 分，**伤害占比是第一要素**：
  `40 × min(队伍对英雄伤害占比 / 30%, 1)`（最高 40，5 人均分 20%，达到 30% 即满分）
  `+ 25 × min(KDA / 6, 1) + 15 × min((击杀 + 助攻) / 对局分钟 / 2, 1) + 胜利 20 分`。
  `KDA = (击杀 + 助攻) / max(死亡, 1)`；悬停分数可看每项得分，页面可展开完整规则。
  伤害数据不可用的对局（重开、资料不足、不适用该模式）按其余三项折算成百分制，不把缺失当作零。
  分数是自定义娱乐参考，受模式节奏影响，不代表官方实力或段位。
- 等级按用户指定顺序：💣Dick🐎（90–100）、BigDick🐎（75–<90）、MiddleDick🐎（60–<75）、
  SmallDick🐎（45–<60）、小男娘🐎（0–<45）。
- 好友关系来自当前账号的 `/lol-chat/v1/friends`，使用 PUUID / 召唤师 ID 匹配，不按昵称猜测。
  最多缓存 60 秒，切换账号自动失效；接口异常或缺少身份时标记未知，不误报为非好友。

## 当前对局与开局提醒

### 默认账号与历史搜索

- 启动并连接客户端后，输入框为空时自动查询当前登录账号的战绩；「我的战绩」按钮可随时切回当前账号。已经输入或正在查看其他玩家时，不会被后台账号检测覆盖。
- 成功查询后保存最近 20 位玩家，重复查询自动置顶。历史搜索按 PUUID 重新读取资料，改名后更新显示名称，不使用旧昵称猜测玩家。
- 支持删除单条和清空记录。历史仅保存在本机 `%LOCALAPPDATA%\LOL战绩查询\search-history.sqlite3`，更换 EXE 或重启后仍保留；自动加载本人不会挤占历史记录，不保存客户端认证凭据。

### 队友评价（进入游戏自动发送）

- 进入游戏后自动把我方队友（不含自己和电脑）的近期战绩快评发进队伍聊天，每局只发一次；标题带应用名「恁🐎战绩查询」，末行附开源项目地址 https://github.com/lifeiyu-44/lol-battle-query。
- 「当前对局」工具栏的「进入游戏自动发送」开关可随时关闭/开启，状态保存在本机；关闭后仍可点「一键发送队友评价」手动发送。
- 自动发送会等战绩摘要加载完成（最多约 15 秒，超时按已加载内容发送）；选人阶段可用手动按钮发到选人房间聊天，对局进行中发队伍频道（旧客户端缺该接口时自动回退到对局聊天室）。
- 评价基于页面已加载的最近 20 场摘要，未加载完的队友显示「近期战绩暂不可查」；每条超长自动截断，最多 9 条，发送间隔 0.3 秒防刷屏。
- 发送失败（例如聊天接口不可用）只弹提示不打断使用；对局结束或切换对局后未发的队列自动作废。

### 英雄专项分析

- 点击战绩列表的英雄头像，可分析当前玩家使用该英雄的表现；对局详情中点击任意玩家的英雄头像，会按该玩家的真实 PUUID 单独查询。当前对局中已公开身份和英雄的头像也支持此入口。
- 独立扫描该玩家最近最多 500 场可获取战绩，筛选指定英雄，可继续按对局类型筛选。此范围不受主列表的 20～500 场设置或日期筛选影响，也不代表账号全部历史。
- 打开时立即复用主列表已取得的完整历史数据，从尚未获取的位置继续扫描。同一玩家的扫描结果缓存 5 分钟，切换英雄无需重复扫描；「刷新最新战绩」可清除缓存重新查询。并发打开会共享正在读取的同一页，列表只在筛选结果变化时更新。
- 扫描按每批 3 页并发拉取（每页 20 场），比逐页串行快约一倍以上；授权令牌一次获取后整个扫描复用，翻页不再重复请求客户端接口。令牌被拒时自动重取一次，仍失败按普通错误提示并可重试。
- 扫描期间显示加载特效：转圈 + 进度条（按 500 场上限推进，带流光动画）与「正在批量扫描战绩 N / 500 场上限」文案，英雄头像同步呼吸光效；扫描结束后自动隐藏，统计随扫描实时刷新。
- 展示英雄战绩列表、有效场数、胜率、累计 KDA、逐场评分及总体均分；去重，排除重开和资料不足的场次。沿用现有娱乐评分公式。
- 点击列表中任意一场可直接打开该场对局详情（按该页玩家的 PUUID 标记「我方」，与该玩家对局时一致）；关闭详情后回到默认「查询」首页，英雄专项的扫描结果仍在缓存中，重新打开即可继续。
- 锐评依据本次样本的胜率、评分、KDA 和死亡表现；不足 5 场不下强结论，5～9 场注明样本偏少。加载中、停止或失败时明确标注当前样本评分，支持继续和重试。

### 页面结构与优选海克斯

- 界面分为「查询 / 对局 / 海克斯」三个独立页面，左侧导航直接切换，不再是一条长页面来回滚动。
  「查询」放召唤师查询、筛选、玩家汇总，以及紧接其后的战绩列表、排序与导出；
  「对局」放当前对局与优选海克斯；「海克斯」放胜率与强度分析。
  任意浮层（英雄专项、对局详情）关闭后一律回到默认的「查询」页，也可以点遮罩或按 Esc 关闭，不必非要点「关闭」按钮。
- 「对局」页在「当前对局」正下方是「优选海克斯」：按英雄维护一份强化优先级清单
  （`%LOCALAPPDATA%\LOL战绩查询\augment-preferences.json`，纯本地、不上传，每个英雄最多 12 个）。
  支持按名称或 ID 搜索添加、逐条移除、上移调整优先级；进入对局后会自动跟随你正在使用的英雄。
- 说明：客户端只在对局内提供强化三选一，**没有公开“自动选择强化”的接口**，
  所以这里只做优先级备忘录，实际选择仍需你在游戏内按顺序挑。

### 对局状态

- 应用运行时每 5 秒检查客户端状态，显示大厅、匹配与确认状态；从英雄选择阶段开始识别当前对局，继续跟踪载入、对局中和重连。
  每 5 秒检查选人、禁选和名单变化，有变化立即刷新（对方锁定英雄同样触发）；我方显示预选、选择中或已锁定，双方显示已确认的禁选英雄。对手未公开的预选和身份不显示。
  选人阶段双方名单来自对局会话，不会被选人数据替换：排位 / 匹配 / 自选自定义里对方玩家从选人阶段起就显示身份与战绩，锁定英雄立即显示（客户端不公开预选）。
  人机类模式的电脑名单在选人阶段客户端不公开（任何工具都无法提前获知）；进入对局后自动改读游戏客户端对局数据接口，立即补齐对方 5 个电脑的英雄与分路。
  自定义房间（`gameType` 为 `CUSTOM_GAME`）全员在同一大厅：从进入大厅起就按我方 / 对手展示双方全部成员，可在选人前查看对手身份与近期战绩；
  匹配 / 排位大厅只有自己的队伍，不按双方展示，避免把队友误当成对手。大厅阶段只展示不弹提醒窗，开始选人后自动切换为选人数据。
  从载入阶段开始补齐已公开身份与战绩；尚未完整时继续重试，不必等到开局。战绩加载与选人刷新独立，同一玩家的战绩请求会复用。
- 每场对局只弹出一次独立提醒窗口，可关闭，也可点「查看当前对局」返回主界面。
  关闭提醒后不重复打扰；新对局会再次提醒，应用主窗口关闭时提醒窗口一并关闭。
- 提醒窗口记住用户拖到的位置（写入 `%LOCALAPPDATA%\LOL战绩查询\notice-window.json`），下次对局在原位弹出，不再每次都回到屏幕中央；
  坐标落在所有屏幕之外（例如换了显示器）时自动丢弃，改回居中显示。
- 主界面常驻「当前对局」栏，显示我方 / 对手的英雄、完整 ID、好友关系、最近最多 20 场胜率、KDA 和平均评分。
  两个玩家并发加载摘要；可复制 ID，或点「查看战绩」按所选 20～500 场范围展开。
  近期摘要使用各类对局，重开不计胜率、KDA 和评分；不包含当前未结束对局。
- 名单只读取客户端已公开的 PUUID / 召唤师身份，不通过昵称猜测或揭示匿名玩家。
  身份缺失、电脑玩家、单人历史不可用分别显示说明；刷新可重试。
  观战或无法识别本人时显示蓝方 / 红方；斗魂竞技场和云顶之弈暂不按双方分组。
- 对局检测使用本地 `/lol-gameflow/v1/gameflow-phase` 和 `/lol-gameflow/v1/session`，
  进入对局后仍需保持英雄联盟大厅客户端和本应用运行。

## MVP / SVP 显示

列表、双方详情和 CSV 显示本工具估算的 MVP / SVP，并始终标注「估算」。
胜方队内娱乐评分最高为 MVP，败方最高为 SVP，使用与五档评分完全相同的公式。
同分并列；重开、十人资料不完整、胜负不明确时不评选。
当前抽查的 SGP 数据没有明确的官方 MVP / SVP 字段，候选 PlayerScore 字段均为零，
因此不会将本工具结果当作腾讯、WeGame 或 OP.GG 官方称号。

## 完整历史分页与伤害占比

- 国服旧 LCU 历史接口可能忽略分页参数并重复返回最新 20 场；这不代表账号只有 20 场历史。
  现在优先调用腾讯 SGP 的 `startIndex` / `count` 分页，已实测 20 + 20 + 10 页取得 50 场不同对局。
- 扩展接口不可用时，首页可显示 LCU 缓存并注明限制；后续分页错误保留游标，允许重试。
  不把重复记录、授权失败或网络错误显示为“历史不足”。
- 令牌只在内存中使用，仅发送到固定白名单的腾讯 `*.lol.qq.com` 战绩服务；验证 HTTPS 证书、禁止重定向，
  不把令牌或带玩家标识的请求 URL 写入日志。
  国服节点参考 [LeagueAkari 服务配置](https://github.com/LeagueAkari/LeagueAkari-Config/blob/main/config/sgp/league-servers.json)。
- 列表和单局详情显示「队伍伤害占比」：玩家对英雄伤害 / 全队对英雄总伤害；数据缺失或全队伤害为零时显示未知。
  CSV 包含同一占比。与「最近 20 场全场伤害最高次数占比」分别统计。

## 限制说明

- 必须在本机登录游戏客户端（LCU 接口只对登录客户端的本机开放，这也是
  Seraphine、League-Toolkit 等工具的工作方式）。
- 需要完整 `名字#Tag`：当前国服客户端已下线「仅按名字」查询接口
  （实测 422/404），且只有匹配到过的玩家才能查到。
- 筛选范围是客户端已返回的战绩，可继续「加载更多」或「加载至所选上限」；
  客户端未开放的历史记录无法通过筛选取回。
- 海克斯 ID（`playerAugment1~6`）通过客户端
  `/lol-game-data/assets/v1/cherry-augments.json` 解析中文名称、稀有度和图标。
  图标由后端读取本地资源并传给界面，不向前端暴露客户端认证信息。
- 内置 `app/augments_cache.json` 名称缓存；客户端资料不可用时尝试
  [CommunityDragon 中文资料](https://raw.communitydragon.org/latest/plugins/rcp-be-lol-game-data/global/zh_cn/v1/cherry-augments.json)，
  更新缓存写入 `%LOCALAPPDATA%\LOL战绩查询\augments_cache.json`。
  尚未收录的强化显示「未知海克斯（资料待更新）」；鼠标悬浮徽章可查看稀有度、名称、
  详细效果描述以及 ID，未收录效果时明确提示以游戏内说明为准；
  没有强化记录时明确提示客户端未提供，图标不可用时保留名称和占位图。
- 英雄名称内置缓存；173 位英雄头像来自本机英雄联盟客户端资源，随应用打包，可离线显示。新增英雄优先从客户端读取并缓存头像，最后才回退腾讯 CDN。
- 打包时必须把 `app/champions_cache.json` 与 `app/augments_cache.json` 一并写入 EXE，
  否则英雄名会退化为「英雄#ID」并在首个查询时同步等待网络资料。
- 装备图标同样优先读取客户端（`items.json` 图标路径），缓存到 `%LOCALAPPDATA%\LOL战绩查询\item-icons`，
  客户端与缓存都不可用时才回退腾讯 CDN；代理或 VPN 导致 CDN 不可达时，详情里的装备仍能正常显示。

## 开发

```
python -m venv .venv
.venv\Scripts\pip install pywebview pyinstaller requests psutil
.venv\Scripts\python -m app.main        # 本地运行（需登录客户端）
build.bat                               # 打包：读取 build.spec，输出 dist\恁🐎战绩查询.exe
test\mock.html                          # 假数据页面，浏览器打开可调试 UI
python -m unittest discover -s test -p "test_*.py"  # 资料解析、缓存及接口字段测试
node test/ui.cjs                        # 浏览器回归（需安装 playwright 和 Edge）
node test/analysis.cjs                  # 个人海克斯统计计算测试
node test/ratings.cjs                   # 评分公式、边界及等级测试
node test/damage.cjs                    # 伤害最高占比与 30% 阈值测试
node test/pagination.cjs                # 20~500 场、数量切换、历史不足及停止/续传测试
node test/current-game.cjs              # 自动检测、单次提醒、双方战绩及一键查询测试
```

打包说明：EXE 名字（含中文和 emoji）只写在 UTF-8 的 `build.spec` 里，`build.bat` 与构建命令
保持纯 ASCII。**不要把 `--name` 放到命令行**：`cmd` 按 GBK 解析参数，emoji 会被拆成乱码，
生成的 exe 名字也就乱了。手工打包等价于
`.venv\Scripts\pyinstaller.exe --noconfirm --clean build.spec`。

## 目录结构

- `app/lcu.py` — LCU 连接（进程检测、认证、请求封装）
- `app/query.py` — 查人 / 战绩分页 / 单局详情 / 数据精简
- `app/champions.py` — 英雄、装备中文名与图片映射（腾讯 CDN + 本地缓存）
- `app/augments.py` — 海克斯中文资料、客户端图标读取与缓存
- `app/references.py` — 公开海克斯强度与英雄搭配参考、来源元数据及缓存
- `app/ui/analysis.js` — 个人海克斯胜率及英雄搭配统计
- `app/ui/` — 界面（原生 JS，无框架）
- `app/main.py` — pywebview 窗口与 JS API 桥
