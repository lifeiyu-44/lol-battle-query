# LOL 国服战绩查询

输入玩家 ID 查询《英雄联盟》国服战绩的桌面工具。基于客户端本地 LCU 接口，
对局数据来自你自己登录的官方客户端，不上传玩家或战绩数据。
静态资料优先读取客户端；必要时联网获取腾讯 CDN / CommunityDragon 的公开资源。

## 使用方法

1. 双击 `LOL战绩查询.exe`（无需安装，免费分享）。
2. 通过 WeGame 登录《英雄联盟》客户端，进入大厅（工具会自动检测并连接）。
   只打开 WeGame 不够；无需进入对局，英雄联盟客户端可以放在后台。
3. 在工具顶部输入玩家 ID，点「查询」：
   - 需输入完整 `名字#Tag`（如 `峡谷之巅#5177`）；Tag 可在对方生涯页查看；
   - 首次进入自动加载最近 20 场；若客户端分页只返回重复记录，程序会停止并提示；
   - 「对局类型」可选择海克斯大乱斗（含匹配 2400、自定义 3270）、极地大乱斗、排位、匹配等；
   - 可按开始日期和结束日期筛选，日期采用本机时区，包含结束日期当天；
   - 列表显示每场对局日期和时间，以及海克斯中文名称、图标和稀有度；
   - 点击任意一场可查看两队 10 人详情，每位玩家的海克斯完整列在其数据下方；
   - 每位玩家名字旁有「复制 ID」，优先复制完整 `名字#Tag`；若接口没给 Tag，提示只能复制名称；
   - 显示「好友 / 非好友 / 本人 / 好友状态未知」，始终相对于本机当前登录账号，无法查看别人的好友关系；
   - 统计和「导出 CSV」均使用当前筛选结果，CSV 包含对局时间和海克斯名称。

## 海克斯分析

- **个人战绩分析**：按当前类型、日期和英雄筛选，统计选择海克斯后的胜率、胜场、场次及英雄搭配表现。
  只计海克斯大乱斗，排除重开；同场同海克斯只计一次。缺少强化记录的对局不会算作「未选择」。
  选取/未选取各至少 10 场才比较表现，胜率相差至少 5 个百分点标记偏高或偏低，其余标记接近；
  英雄搭配只与同一英雄未选取该海克斯的记录比较。样本不足仍显示真实胜率和场次。
  这是个人战绩相关性，不是全服强度、因果收益或对英雄机制的适配判定。
- **公开强度 / 英雄适配**：只需联网，不必启动 WeGame 或游戏客户端。
  选择全部英雄查看公开海克斯胜率与 T1–T5 梯队，选择具体英雄查看搭配胜率、梯队和样本数。
  来源为 [ARAMGG 公开海克斯榜](https://aramgg.com/en/augments) 及其公开英雄详情数据。
  来源的总体榜声明使用腾讯国服资料；英雄详情的胜率来自 ARAMGG 客户端上传样本（区域按源数据标记），
  不应视为官方全服胜率。T1 最高，梯队沿用来源，不等同于白银/黄金/棱彩稀有度。
- 公开参考标注来源、来源版本、日期、获取时间及可用样本数；没有提供的数据标为未知，不写成 0%。
  不同页面可能使用不同版本编号格式（如 `26.17` / `16.17`），保留来源原值。
  公开参考不随个人日期筛选；缓存 6 小时，可手动刷新，联网失败时明确标注旧缓存。
  缓存存放于 `%LOCALAPPDATA%\LOL战绩查询\references`，不会向公开服务上传玩家或对局数据。

## 娱乐评分与好友标记

- **伤害评价**：后台读取完整十人详情，显示对英雄伤害的全场排名、全场最高及并列最高。
  对当前类型/日期筛选下最近 20 场非重开对局，计算「伤害最高场次 / 已核验适用场次」，
  占比达到 30%（含 30%）显示达标。并列最高计入，十人全为零不计最高。
  缺少十人数据或身份无法确认时显示统计未完成，可重试；竞技场等非十人模式不参与。
  更早对局可点开详情核验；伤害评价与原娱乐评分分别显示。

- 战绩列表、十人详情显示单局评分；玩家信息栏显示当前筛选下的平均分，排除重开及资料不足的对局。
  列表可按评分降序，详情可在各队内按评分降序，CSV 也包含分数和等级。
- 总分 100 分：`60 × min(KDA / 6, 1) + 20 × min((击杀 + 助攻) / 对局分钟 / 2, 1) + 胜利 20 分`。
  `KDA = (击杀 + 助攻) / max(死亡, 1)`；悬停分数可看每项得分，页面可展开完整规则。
  分数是自定义娱乐参考，受模式节奏影响，不代表官方实力或段位。
- 等级按用户指定顺序：恁🐎👍（90–100）、BJ🐎（75–<90）、MJ🐎（60–<75）、
  SJ🐎（45–<60）、No🐎（30–<45）、XN🐎（0–<30）。
- 好友关系来自当前账号的 `/lol-chat/v1/friends`，使用 PUUID / 召唤师 ID 匹配，不按昵称猜测。
  最多缓存 60 秒，切换账号自动失效；接口异常或缺少身份时标记未知，不误报为非好友。

## 限制说明

- 必须在本机登录游戏客户端（LCU 接口只对登录客户端的本机开放，这也是
  Seraphine、League-Toolkit 等工具的工作方式）。
- 需要完整 `名字#Tag`：当前国服客户端已下线「仅按名字」查询接口
  （实测 422/404），且只有匹配到过的玩家才能查到。
- 筛选范围是客户端已返回的战绩，可继续「加载更多」或「加载全部战绩」；
  客户端未开放的历史记录无法通过筛选取回。
- 海克斯 ID（`playerAugment1~6`）通过客户端
  `/lol-game-data/assets/v1/cherry-augments.json` 解析中文名称、稀有度和图标。
  图标由后端读取本地资源并传给界面，不向前端暴露客户端认证信息。
- 内置 `app/augments_cache.json` 名称缓存；客户端资料不可用时尝试
  [CommunityDragon 中文资料](https://raw.communitydragon.org/latest/plugins/rcp-be-lol-game-data/global/zh_cn/v1/cherry-augments.json)，
  更新缓存写入 `%LOCALAPPDATA%\LOL战绩查询\augments_cache.json`。
  尚未收录的强化显示「未知海克斯（资料待更新）」，ID 仅保留在悬浮提示中；
  没有强化记录时明确提示客户端未提供，图标不可用时保留名称和占位图。
- 英雄名称/头像来自腾讯官方资料站 CDN（game.gtimg.cn），首次联网自动缓存。

## 开发

```
python -m venv .venv
.venv\Scripts\pip install pywebview pyinstaller requests psutil
.venv\Scripts\python -m app.main        # 本地运行（需登录客户端）
build.bat                               # 打包单文件 exe 到 dist\
test\mock.html                          # 假数据页面，浏览器打开可调试 UI
python -m unittest discover -s test -p "test_*.py"  # 资料解析、缓存及接口字段测试
node test/ui.cjs                        # 浏览器回归（需安装 playwright 和 Edge）
node test/analysis.cjs                  # 个人海克斯统计计算测试
node test/ratings.cjs                   # 评分公式、边界及等级测试
node test/damage.cjs                    # 伤害最高占比与 30% 阈值测试
```

## 目录结构

- `app/lcu.py` — LCU 连接（进程检测、认证、请求封装）
- `app/query.py` — 查人 / 战绩分页 / 单局详情 / 数据精简
- `app/champions.py` — 英雄、装备中文名与图片映射（腾讯 CDN + 本地缓存）
- `app/augments.py` — 海克斯中文资料、客户端图标读取与缓存
- `app/references.py` — 公开海克斯强度与英雄搭配参考、来源元数据及缓存
- `app/ui/analysis.js` — 个人海克斯胜率及英雄搭配统计
- `app/ui/` — 界面（原生 JS，无框架）
- `app/main.py` — pywebview 窗口与 JS API 桥
